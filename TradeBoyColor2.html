❓ HOW TO TRADE

1. LINK UP

Host: press START on the green Game Boy to get a Buddy Code and share it.

Buddy: type the code on the teal Game Boy and press A.

2. SEND FILES

Once linked, either player picks a file on the green Game Boy and presses A. The other player sees what is coming (name, type, size...) and chooses to accept or decline before anything is sent.

Tick Auto-accept transfers at the top to skip the prompts (off by default).

3. CHAT

A chat box opens under the Game Boys when you are linked. Use 😀 for emojis and 🖼️ to send a picture (you can also paste one).

Press SELECT on the green Game Boy (or ✏ NAME) to change the name your buddy sees.

4. MUSIC & SOUND

🎵 MUSIC plays one of 3 looping trading room tracks (◀ ▶ to change). SFX controls the beeps.

5. TESTING SOLO

⚡ Self-Link Test connects the two Game Boys to each other so you can try everything alone.

[B] on either Game Boy disconnects.
